## Déployer sur GitHub + Vercel
1. Créez un nouveau dépôt GitHub, par exemple `contrepoidstech`.
2. Téléversez les 4 fichiers à la racine du dépôt (`index.html`, `styles.css`, `script.js`, `README.md`).
3. Sur Vercel, choisissez **Add New → Project**, importez ce dépôt GitHub.
4. Pour ce site statique, laissez le framework sur **Other** et le build command vide. Si Vercel demande un output directory, utilisez `.`.
5. Cliquez **Deploy**.
